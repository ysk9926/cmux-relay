## Global Constraints
- No new repository; preserve both hosts and existing cmux behavior.
- No API tokens, proxy or Hermes runtime. Official CLI processes only.
- Automatic fallback only for positive quota signals; no automatic replay on ordinary errors.
- User-pinned agent/effort never silently changes provider.
- Verification requires recorded approval plus successful executed commands; model assertions alone never qualify.
- Unknown usage/cost stays null; never infer subscription token limits or prices.

## Review Focus
- Concurrent spawn ownership conflicts must be rejected atomically, including parent/child paths.
- Interrupted worker must not cause stale PID termination or false completion.
- Bad/missing reports and nonzero process exit must never become success.
- Cross-provider retry must preserve brief, scope, cwd and evidence of previous attempts.
- Workflow must stop on failed/needs_input/review failure and before unapproved verification.
